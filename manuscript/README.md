# Manuscript

`kenya-olympic-gold-manuscript.docx` — the full draft: table of contents, 12
sections, 3 data tables, 6 figures, written for submission consideration to
*International Journal of Sport Policy and Politics*. Every number in it
traces back to a file in `data/`; nothing here is asserted beyond what the
dataset backs.

The structure follows the standard shape of an empirical policy paper:
introduction, data and methods, the medal record, event and gender
breakdowns, the governance network analysis, the anti-doping timeline, the
transparent response scorecard, welfare, literature positioning, limitations,
and conclusion. Section 6 (the network graph) and section 8 (the scorecard)
are the two genuinely new analytical contributions — I haven't found either
built for Kenya, or for any single Olympic nation, anywhere else.

This is a first full draft, not a final submission. The honest limitations
section says plainly where the dataset is still thin (the controversies
corpus, the NLP classifier's weaker categories) rather than hiding it.
